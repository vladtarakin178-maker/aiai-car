# AIAI-Car 🚗🤖

Быстрая машинка с искусственным интеллектом, которая сама находит дорогу.
Школьный проект по робототехнике (9 класс).

## Как это работает
- **Raspberry Pi 4** с камерой — «мозг»: нейросеть (Python, OpenCV / TensorFlow Lite) смотрит на дорогу и решает, куда рулить.
- **Arduino** — управляет моторами и ультразвуковым датчиком, страхует от столкновений.
- **Bluetooth / телефон** — ручной режим управления.

## Детали
| Деталь | Зачем |
|---|---|
| Raspberry Pi 4 (4 ГБ) + microSD 32 ГБ | ИИ и обработка видео |
| Камера Raspberry Pi Camera Module 3 | видит дорогу |
| Arduino Uno / Nano | моторы и датчики |
| Алюминиевое шасси + моторы 25GA (300–500 об/мин) | быстрая езда |
| Драйвер моторов TB6612FNG | управление моторами |
| Датчик HC-SR04 | расстояние до препятствий |
| Модуль HC-05 | Bluetooth-управление |
| 2× аккумулятора 18650 + понижающий модуль 5 В | питание |

## План
1. Собрать шасси и проверить моторы
2. Arduino: езда + объезд препятствий
3. Raspberry Pi: камера и распознавание дороги
4. Связать Pi и Arduino
5. Обучить и протестировать
6. Презентация к защите

## Безопасность
Платы крепить на пластиковых стойках (алюминий проводит ток). Аккумуляторы 18650 заряжать только со взрослыми.
